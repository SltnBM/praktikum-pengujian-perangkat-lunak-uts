# Evidence Pengujian UTS - Kelompok 3

Folder penampung seluruh bukti pengujian kelompok sesuai ketentuan Soal UTS Bagian F:
- `screenshots/`: Tangkapan layar bukti bug (format: BUG-001_judul-singkat.png) dan komparasi antarmuka.
- `recordings/`: Rekaman video untuk bug intermiten / alur interaksi kompleks.
- `logs/`: Cuplikan log konsol browser / error JavaScript.
- `session-notes/`: Berkas catatan sesi pengujian eksploratif (SBTM) oleh R3 dengan akumulasi rasio waktu 100%.
