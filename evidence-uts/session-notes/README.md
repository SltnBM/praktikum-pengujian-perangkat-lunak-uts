# Session Notes - Exploratory Testing (SBTM)

Simpan berkas Session Notes hasil pengujian eksploratif (SBTM) R3 di sini.

## Panduan Penggunaan:
1. Gunakan templat baku: [`TEMPLATE_SESSION_NOTE.md`](./TEMPLATE_SESSION_NOTE.md).
2. Buat berkas untuk masing-masing sesi:
   - Sesi 1: `session-01.md` (Tester: R3 / Lutfi)
   - Sesi 2: `session-02.md` (Tester: R3 / Lutfi)
3. Durasi masing-masing sesi: Tepat **30 menit** (time-boxed).
4. Pastikan rasio distribusi waktu berjumlah **100%**.
5. Lakukan debrief dengan Test Lead (R1 / Sultan) sebelum eskalasi ke GitHub Issues (maksimal 2 bug per sesi).
